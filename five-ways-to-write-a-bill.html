Method A

The Copier

Real name: k-Nearest Neighbors (kNN)

Finds the most similar customer it has seen and copies their whole bill.

Ana's bill Most similar customer: Internet (only 1 option different). Copies that bill:
Internet fee ✓Mobile fee missing
Wrong. The neighbor didn't have Mobile, so the copy doesn't either.
GoodVery simple. Always copies a real, complete bill.
BadThe small difference with the neighbor becomes an error on the bill.
Tested: EMR 0.6%On our validation data, about 6 of every 1,000 bills fully right.

Say it like this: "kNN fails here because test customers are new combinations; copying the neighbor copies its differences."

Method B

The 731 Specialists

Real name: Binary Relevance (one classifier per label)

One small expert per bill item. Each one only answers: "does this customer pay my item, yes or no?"

Ana's bill
TV expert:no TV → no
Internet expert:Internet fee ✓
Mobile expert:Mobile fee ✓
Right, if each expert learned its rule well.
GoodEach item learns its own rule, so it works for new combinations.
Bad731 separate models (slow). They don't talk to each other, so together they can write an impossible bill.
To testIn the notebook, first on a small sample.

Say it like this: "Binary Relevance trains one yes/no model per billing column."

Method C

The Rule Tree (and the Forest)

Real names: Decision Tree (multi-output) · Random Forest

One expert that learns if → then rules and fills all the boxes at once. A Random Forest is many trees that vote.

Ana's bill Has TV? no → no TV fee Has Internet? yes → Internet fee Has Mobile? yes → Mobile fee
Internet fee ✓Mobile fee ✓
Right, because it learned the rules, not whole bills.
GoodWorks for new combinations. Easy to explain ("if X then Y"), which helps in Sprint 3. One line in scikit-learn.
BadWith 731 items it can be slow. One tree can memorize too much; the forest reduces that, but is slower.
To testIn the notebook, first on a small sample.

Say it like this: "A multi-output tree predicts all 731 columns with one set of rules. A Random Forest averages many trees."

Method D

The Fixed Menu

Real name: Label Powerset

Treats each complete bill as one dish on a menu and picks one. It can only serve bills it has seen before.

Ana's bill Menu: TV fee · Internet fee · TV fee + Internet fee
"Internet fee + Mobile fee" is not on the menu
Wrong. Her bill was never seen, so it can't be chosen.
GoodAlways gives a real, coherent bill.
BadCan't create new bills.
Ruled outOnly 3.5% of the test bills exist in train, so it would fail on 96.5%.

Say it like this: "Label Powerset is ruled out: almost none of the test bills appear in train."

Not a method, a step before the method

MCA: The Summarizer

Real name: Multiple Correspondence Analysis. It doesn't write bills. It shrinks the 743 options into fewer "summary" columns, and then a method (A, B or C) uses those.

743 options→MCA (summarize)→e.g. 50 columns→Method B or C→bill

Risk: a summary keeps the big patterns and can lose rare options, and many bill items are rare. That's why we test with and without MCA.
